## 📌 Project Overview

This project presents a complete **Coffee Shop Sales Analysis Dashboard** built in **Power BI**.

The dashboard transforms raw coffee shop transaction data into meaningful visual insights to help understand:
- Sales performance
- Profit trends
- Peak business hours
- Customer purchasing behavior
- Product category performance

**Total Data:** 4,000+ transactions | March 2024 - March 2025

---

## 🎯 Project Objectives

✔ Analyze overall sales and profit performance  
✔ Identify top-selling coffee products  
✔ Understand hourly and daily sales trends  
✔ Compare payment methods (Card vs Cash)  
✔ Create attractive heatmap for peak hours  
✔ Generate business insights for decision-making
